In diesem Ordner dokumentieren wir die Entscheidungen, die wir als Team im Requirements-Engineering-Prozess treffen.

Zu jeder Entscheidung halten wir fest:
- **Entscheidung:** was entschieden wurde
- **Grund:** warum
- **Alternative:** welche andere Möglichkeit es gab (falls vorhanden)

So bleibt nachvollziehbar, warum der Anforderungskatalog so aufgebaut ist.
